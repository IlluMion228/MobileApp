# NoteApp - Мобилно приложение за бележки с ИИ интеграция

Това е проект за дисциплината "Разработка на мобилни приложения". Приложението представлява модерен бележник за Android, който съчетава локално съхранение на данни с възможностите на изкуствения интелект.

## 🚀 Функционалности
- **CRUD операции:** Създаване, преглед, редактиране и изтриване на бележки.
- **Локална база данни:** Използване на Room за персистентност на данните.
- **Мултимедия:** Възможност за добавяне на снимка към всяка бележка чрез камерата.
- **Търсене:** Бързо филтриране на бележки по заглавие или съдържание.
- **Споделяне:** Изпращане на съдържанието на бележката към други приложения.
- **🤖 Интеграция на ИИ (Gemini):**
    - **Обобщаване:** Автоматично генериране на кратко резюме на дълги бележки.
    - **Подобряване на текст:** Корекция на граматика и стилистично оформяне на текста чрез ИИ модел.

## 🛠 Технологичен стек
- **Език:** Kotlin
- **UI:** Jetpack Compose (Material 3)
- **Архитектура:** MVVM (Model-View-ViewModel)
- **База данни:** Room DB
- **Изображения:** Coil


## 📥 Инструкции за стартиране
1. Клонирайте хранилището: `git clone <repo-url>`
2. Отворете проекта в **Android Studio (Ladybug или по-нова)**.
3. Изчакайте Gradle синхронизацията.
4. Добавете вашия Gemini API ключ в `app/src/main/java/com/example/noteapp/utils/GeminiAiHelper.kt`.
5. Стартирайте приложението на емулатор или реално устройство (API 24+).
