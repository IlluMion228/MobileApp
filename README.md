# NoteApp (MobileApps2025-<2301321085>)

##  Идея
Приложението позволява на потребителите бързо и лесно да създават, четат, редактират и изтриват лични бележки. Целта е да се предостави изчистен интерфейс (Material 3) и надеждно локално съхранение на данните, като същевременно се демонстрират модерни Android технологии.

##  Как работи
Потребителят стартира приложението и вижда списък с текущите си бележки.
1.  **Добавяне:** Чрез бутона "+" се отваря екран за нова бележка.
2.  **Редакция:** При клик върху съществуваща бележка, тя се отваря за редакция.
3.  **Изтриване:** Всяка бележка може да бъде изтрита чрез бутон (кошче).
4.  **Споделяне:** При редакция или създаване, бележката може да бъде споделена (Share Intent) към други приложения (напр. Viber, Messenger, Email).
5.  **Съхранение:** Всички данни се пазят локално в SQLite база данни чрез Room, така че са налични и след рестарт на телефона.

##  Архитектура
Приложението следва **MVVM (Model-View-ViewModel)** архитектурен шаблон с Repository слой:

*   **UI Layer (View):** Изграден изцяло с **Jetpack Compose**. Съдържа екраните (`HomeScreen`, `AddEditScreen`) и навигацията.
*   **ViewModel:** (`NoteViewModel`) Управлява състоянието на UI и комуникира с Repository слоя. Използва `StateFlow` за реактивно обновяване на данните.
*   **Repository:** (`NoteRepository`) Абстрахира източника на данни.
*   **Data Layer (Model):**
    *   **Room Database:** Локална база данни.
    *   **DAO:** Обект за достъп до базата (SQL заявки).
    *   **Entity:** (`Note`) Моделът на данните.

##  Потребителски поток (User Flow)
1.  Start App -> **Home Screen** (List of Notes).
2.  Click "Add" (+) -> **Add/Edit Screen** (Empty fields).
3.  Click "Note Item" -> **Add/Edit Screen** (Pre-filled fields).
4.  Click "Save" (Check icon) -> Save to DB -> Return to **Home Screen**.
5.  Click "Share" -> System Share Dialog.
